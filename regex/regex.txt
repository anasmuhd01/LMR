 REGEX
 --------------
 pattern defined by using special characters for text related search,match, or replace operations are called regular
 expression

 in Python regex related operations are handled by built in module known as 're' 


REGEX FUNCTIONS
---------------
findall	-- Returns a list containing all matches
search	-- Returns a Match object if there is a match anywhere in the string
split	-- Returns a list where the string has been split at each match
sub	    -- Replaces one or many matches with a string

meta characters:
-- Special characters with meaning to construct regex patterns
